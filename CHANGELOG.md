# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-15

### Added
- Initial release of HMS website with 7 pages
- Initial release of FundiPro website with 6 pages
- Full Kenyan localization for both websites
- Mobile-first responsive design
- Form validation and interactive features
- Kenya Data Protection Act 2019 compliance
- M-Pesa payment integration mentions
- Kenyan insurance provider support
- Emergency number localization (999/112)
- +254 phone format throughout
- Dynamic copyright year
- Accessibility features (WCAG 2.1 AA)

### HMS Features
- Patient portal access
- Online appointment booking
- Department directory with open/closed status
- Contact form with spam protection
- Google Maps integration
- FAQ section
- Services overview
- Doctor profiles
- Emergency contact information

### FundiPro Features
- Service catalog (14+ trades)
- Professional profiles with verification
- Location-based search
- Pricing page (Free, Pro KES 500, Business KES 1,200)
- Customer testimonials
- Featured professionals
- How It Works section
- Professional registration form

### Technical
- HTML5 semantic markup
- CSS3 with responsive breakpoints
- Vanilla JavaScript (no dependencies)
- 44px minimum tap targets on mobile
- Cross-browser compatibility
- SEO-friendly structure
