# FundiPro Project Plan
## Professional Services Marketplace for Kenya

**Start Date:** August 1, 2026
**Target Launch:** November 2026

### Project Overview
Connect skilled professionals (fundis) with customers across Kenya. Enable fundis to run their businesses and customers to find trusted services.

### Target Users
- **Fundis:** Plumbers, electricians, carpenters, painters, mechanics, tailors, etc.
- **Customers:** Homeowners, businesses needing services

### Core Features

#### For Fundis
- Profile & portfolio management
- Job lead notifications
- Quote submission
- Calendar & scheduling
- Client management
- Invoicing (with M-Pesa)
- Earnings tracking
- Subscription tiers (Free, Pro KES 500, Business KES 1,200)

#### For Customers
- Search by service & location
- Post job requests
- Compare quotes
- Review & rating system
- M-Pesa payments
- Job history

### Tech Stack
- Backend: PHP 8+, MySQL
- Frontend: HTML5, CSS3, JavaScript
- Payment: M-Pesa Daraja API
- SMS: Africa's Talking
- Location: Kenyan counties & towns

### Development Phases
1. **Phase 1 (Aug):** Core models & authentication
2. **Phase 2 (Sep):** Professional profiles & job matching
3. **Phase 3 (Oct):** Payments & subscriptions
4. **Phase 4 (Nov):** Launch preparation
