# FundiPro Website

A complete, professional website for FundiPro - a platform connecting skilled professionals (fundis/artisans) with customers seeking home and business services.

## Features

### Pages
- **Home (index.html)** - Landing page with hero, search, stats, services, how it works, featured professionals, and testimonials
- **About (about.html)** - Mission, vision, company story timeline, core values, and team members
- **Services (services.html)** - Detailed service categories with pricing, descriptions, booking steps, and FAQ
- **Professionals (professionals.html)** - Browse professionals with advanced filtering and sorting
- **Contact (contact.html)** - Contact information, form, map, and quick help links

### Design Features
- Modern, clean, mobile-first responsive design
- Vibrant color scheme (blues #1a73e8, #0d47a1 and oranges #ff6b35, #f4511e)
- Google Fonts: Poppins for headings, Inter for body text
- Smooth animations and transitions
- Semantic HTML5 structure
- Accessibility-compliant with ARIA attributes
- Cross-browser compatible
- SEO-friendly with proper meta tags

### Interactive Features
- Sticky navigation with scroll effects
- Mobile hamburger menu
- Smooth scrolling for anchor links
- Animated statistics counter
- Intersection Observer for scroll animations
- FAQ accordion
- Professional filtering and sorting
- Form validation with error messages
- Success modal for form submission
- Back-to-top button

### Colors

### Fonts
Update the Google Fonts import URL in `style.css`

Edit HTML files directly - all content is clearly structured with semantic classes
