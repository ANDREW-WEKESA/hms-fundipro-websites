# HMS Project Plan
## Hospital Management System for Kenya

**Start Date:** July 28, 2026
**Target Launch:** November 2026

### Project Goals
- Build comprehensive hospital management system
- Full Kenya localization (SHA, NHIF, M-Pesa)
- Patient portal and appointment booking
- Pharmacy and lab management
- Mobile-first design

### Tech Stack
- Backend: PHP 8+, MySQL
- Frontend: HTML5, CSS3, Vanilla JS
- APIs: Africa's Talking (SMS), M-Pesa Daraja
- Hosting: Linux server with Apache

### Phases
1. **Phase 1 (Aug):** Database & Core Models
2. **Phase 2 (Sep):** Clinical Features & Portal
3. **Phase 3 (Oct):** Payments & Polish
4. **Phase 4 (Nov):** Testing & Launch

### Kenya Requirements
- Phone: +254 format
- Emergency: 999/112
- Insurance: SHA, NHIF, private providers
- Currency: KES
- Timezone: Africa/Nairobi
