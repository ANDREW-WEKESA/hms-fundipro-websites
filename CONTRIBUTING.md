# Contributing to HMS & FundiPro Websites

Thank you for considering contributing to this project!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Test your changes locally
5. Commit your changes (`git commit -m 'feat: add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Commit Message Convention

We follow conventional commits:

- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation changes
- `style:` Code style changes (formatting, etc.)
- `refactor:` Code refactoring
- `test:` Adding tests
- `chore:` Maintenance tasks

## Code Style

- Use semantic HTML5
- Follow BEM methodology for CSS
- Write vanilla JavaScript (no frameworks)
- Ensure mobile responsiveness
- Test on multiple browsers

## Kenyan Localization Guidelines

- All phone numbers must use +254 format
- Emergency numbers: 999/112
- Currency: KES (not USD)
- Use Kenyan locations and addresses
- Include M-Pesa as payment option
- Reference Kenya Data Protection Act 2019 for privacy

## Testing

Before submitting:

1. Test on mobile devices (320px, 480px, 768px)
2. Check all forms validate correctly
3. Verify all links work
4. Test with keyboard navigation
5. Check color contrast for accessibility

## Questions?

Open an issue for any questions or concerns.
